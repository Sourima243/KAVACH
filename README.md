# Suraksha
Suraksha is a personal safety web application built for women's security in emergency situations. It runs entirely in a web browser — no app store installation, no account creation, and no backend server. 
Everything happens on the user's own device using standard web browser capabilities, and all personal data (contacts, name, phone number) stays stored locally in that browser and never leaves the device.

The core idea: in a moment of danger, a person needs to alert trusted people and share their exact location with the fewest possible taps, ideally without even looking at the screen carefully or typing anything.

Emergency alert:

Hold-to-arm SOS button (2-second hold, 5-second cancellable countdown)
Fetches live GPS location and builds an alert with name, map link, accuracy, and timestamp
Sends the alert via pre-filled SMS to all trusted contacts at once
Per-contact WhatsApp send links
One-tap direct call to your first contact
"Practice run" mode to test the flow without alerting anyone for real

Automatic safety net:

Reach-home timer — set minutes, auto-triggers SOS if you don't check in
Shake-to-alert — three sharp shakes trigger the SOS countdown, even with the phone in a pocket

In-the-moment deterrents:

Siren — synthesized two-tone alarm sound plus a flashing screen strobe and vibration
Fake incoming call — rings after 5 seconds with a realistic call screen and a spoken voice on answer

Location:

Live location sharing — continuously updates a shareable map link while you move

Evidence:

Audio recording — records, plays back, and saves ambient audio

Contacts & profile:

Trusted contacts list (up to 8 people, name + phone)
Your profile — name, phone, and a medical/safety note included in every alert

Helplines (India):

One-tap call buttons: 112 (emergencies), 1091 & 181 (women's helplines), 1098 (Childline), 108 (ambulance), 14416 (Tele-MANAS mental health)

Other

Activity log with timestamps for every action taken
Light/dark theme toggle
"Erase all data" button — everything is stored only on your device
